# Data

This project uses the [UR3 CobotOps dataset](https://archive.ics.uci.edu/dataset/963/ur3%2Bcobotops) from the UCI Machine Learning Repository.

The dataset is not duplicated here. Download `dataset_02052023.xlsx` from UCI, then load it when prompted by the notebook.

Citation:

> Tyrovolas, M., Aliev, K., Antonelli, D., & Stylios, C. (2024). UR3 CobotOps [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5J891
